
# Rock, Paper, Scissors! :joystick:

Game of rock, paper, scissors built for the first week at School of Code.

:joystick: [Play game](https://webshuriken.github.io/SoC-week1-hackathon)

## About

The first hackathon of many during the School of Code bootcamp. Worked along side Connor to create a text based game of rock, paper scissors. All created in one day. Later on the game was improved and with icons. See [Hackathon notes](HACKATHON.md) to read about the challenge.

## Run Locally

1. Close the repo `git clone [https://](https://github.com/webshuriken/SoC-week1-hackathon.git)`
2. Open the `index.html` on a browser and off you go!
